# Historial de desarrollo por slices

Esta carpeta conserva el **diario técnico del desarrollo de Brisa**.

## Cómo leer estos documentos

- `slice-1.md` … `slice-8.md`: documentos principales con objetivos, decisiones, alcance y validación de cada etapa.
- `slice-N-placeholder.md`: notas de transición que se conservaron durante la evolución del proyecto para no romper referencias internas.

## Estado de esta documentación

- Se mantiene como **registro histórico** (no como guía operativa principal).
- La documentación vigente unificada del proyecto está en:
  - `README.md`
  - `docs/architecture.md`
  - `docs/roadmap.md`
  - `docs/contracts/`
